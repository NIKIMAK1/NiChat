## Added
- Smooth chat opening and closing: the chat history and input field fade and slide in when you press T, and fade out when the chat closes.
- HUD messages now cross-fade with the chat screen instead of disappearing instantly.
- New messages smoothly slide in and push older ones up, both in the HUD and in the open chat history.
- Optional automatic translation of chat messages via Google Translate (disabled by default). Hover over a translated message in the chat history to see the original.
- New settings: open/close animation duration, new message fade-in duration, and a Translation tab.

## Changed
- Messages now fade out smoothly instead of being cut off when the HUD message limit is reached.
- Animations use sub-pixel positioning for smoother movement.
