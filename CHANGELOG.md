## Added
- Scrollbar in the chat history: drag it with the mouse or click the track to jump. Can be turned off in Chat History settings.
- Translation of your own sent messages: enable "Translate My Sent Messages" and set the send language (e.g. `en`). If translation fails, the original message is sent.
- Classic message style (General → Message Style) that looks like the vanilla chat: same width, position, line height, scrollbar and popup behavior, following the game's chat width, height and opacity options.
- Optional NiChat formatting and player heads for the classic style, toggled separately.
